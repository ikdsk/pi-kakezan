# 3.14 の かけざん(円周率の掛け算 暗記アプリ)

中学受験で頻出の「3.14 × n」を、小学生が iPhone / iPad で反復して覚えるための静的 Web アプリ。
正解で紙吹雪・コンボ・XP・レベルアップ、実績集め、クリア(エンディング)つき。
ビルド不要のバニラ HTML / CSS / JavaScript(ES modules)、依存パッケージなし、外部通信なし。
仕様は [docs/spec.md](docs/spec.md)。

## モード
| モード | 内容 |
|---|---|
| ひょう | 段ごとの答えの表。答えをタップで隠す/見せる。「ぜんぶ かくす / みせる」 |
| フラッシュカード | 10枚。めくって「おぼえた / まだ」で自己採点(成績・マスターには入れない。おぼえたで XP +3) |
| 4たくクイズ | 10問。隣の段の答え・桁ずれ・数字の入れ替わりなど紛らわしい選択肢 |
| 2タップ チャレンジ | 10問。①「てんの まえ」(整数部)を4択 → ②「てんの あと」(小数部)を4択。2つ選ぶと即判定。1タップ目は「21.□□」と表示され、2タップ目の前なら選び直せる |
| ぎゃくびき | 「? × 3.14 = 21.98」の ? を4択で答える |
| タイムアタック | 基本 9問をランダム順・2タップ式。ベストタイム記録 |
| じっせき | 実績 36 個の一覧・進捗・クリア状況 |
| きろく | 段ごとの正解数/出題数・マスター★・直近の間違い・ベストタイム・リセット |

出題範囲はホームで「きほんだけ(1〜9・既定)/ きほん＋はってん / はってんだけ(12,15,16,18,24,25,36,49,64,81)」から選択。
2タップ(整数部・小数部)で、314n が 100 の倍数になる答え(例 3.14×50=157)の小数部は「なし(.0)」を選択肢に出す。

## 演出・XP・レベル
### コンボ演出(連続正解の数に応じて段階的にエスカレート)
コンボは**まちがえるまで、クイズをまたいで続く**(「もういちど」や別モードへ移っても続く。リロードで 0 に戻る)。
画面にはいつも「🔥 N COMBO」が出て、増えるたびに数字が弾み、炎が増えて色が熱くなる。
どの段階で何を出すかは [`js/combo.js`](js/combo.js) の設計表(`STAGES` など)で決まり、そこを書き換えれば調整できる(純粋関数・テストあり)。

| コンボ | 演出 |
|---|---|
| 1〜2 | 紙吹雪+ボタンが弾む+小さな画面シェイク |
| 3〜4 | 中シェイク+白フラッシュ+「3 COMBO!」が画面中央にスラム(拡大→縮小で叩きつけ)+背景が一瞬色変わり(フラッシュの少しあと)+ドン |
| 5〜9 | 斜めの帯が横切るカットイン(「すごい!!」「とまらない!!」…)+集中線+コンボごとに色が変わるフラッシュ+強シェイク+画面の外周が脈打って光る(コンボが続くあいだ)+紙吹雪増量(左右からも)+和音・ピッチアップ |
| 10〜19 | 全画面カットイン: 帯 2 本がクロス+回転するサンバースト+巨大な数字(残像つき)と「ばくはつ!!」「むてき!!」…+ズームパンチ+虹色フラッシュ+低音ドーン+ファンファーレ |
| 20〜 | **フィーバー**: 虹色の背景がゆっくりうねる+虹の外周+パーティクルが出続ける+ビート(Web Audio)+毎問「FEVER!!」「かみ!!」「えんしゅうりつの かみさま」のカットイン |
| キリ番 10 / 20 / 30 / 50 / 100(以降 100 の倍数) | 特大: 最大 2 秒(タップでスキップ)・シェイク最大・紙吹雪 1.8 倍。「天才!?」「FEVER!!」「かみ!!」「えんしゅうりつの かみさま」「でんせつ!!!!」 |
| コンボが切れた(3 以上から) | ガラスが割れる演出+「コンボ ストップ…」+「さいこう N れんぞく! つぎは もっと いける!」。フィーバーと外周の光・ビートも止まる |

- 不正解は軽いシェイクと正しい答えの表示(3 未満から切れたとき)。「つぎへ」ボタンで進む。
- 通常のカットインは 0.8 秒以内で、正解後の自動送り(0.9 秒)の間に収まる。キリ番だけ最大 2 秒で、そのあいだ自動送りは待つ(タップでスキップ可)。回答後はボタンが無効なので、演出中の誤タップはない。
- 外部ライブラリ・画像・音声ファイルは使わず、CSS アニメーション(`transform` / `opacity` / `scale` 中心)・canvas・DOM・Web Audio 合成だけで作っている。演出のノードとタイマーは必ず掃除される(画面遷移・セッション終了で `stopAll`)。

### 光過敏への配慮(えんしゅつ設定)
- 全画面フラッシュ(白・色・虹・背景ティント)は **1 秒に 2 回まで**(基準の「1 秒に 3 回以下」より厳しく)、間隔 420ms 以上。1 回答で最大 2 回(フラッシュ+少し遅れたティント)。上限は `js/combo.js` の `FLASH_LIMIT` で、超える要求は出さずに捨てる。赤一色の全画面フラッシュは使わない(黄・緑・水色・ピンク・だいだい・虹・白)。
- ホームの「えんしゅつ: **はで** / **ひかえめ**」で切替(保存。既定は はで)。**ひかえめ**と、OS の「動きを減らす」(`prefers-reduced-motion`)のときは、シェイク・フラッシュ・ズーム・サンバースト・外周の光・フィーバー背景・紙吹雪をすべて止めて、**文字のカットインだけ**(「3 COMBO!」「すごい!!」「FEVER!!」…と、コンボ切れの「コンボ ストップ…」)になる。

### XP・レベル・音
- XP: 正解 +10、コンボボーナス(最大 +10)、速さボーナス(2秒以内 +5 / 4秒以内 +2)、実績解除ボーナス(ブロンズ 20 / シルバー 50 / ゴールド 100 / レインボー 300)。
  レベル N→N+1 に必要な XP は `50 + 25×(N-1)`。レベルアップは全画面演出(タップでスキップ)。
- 効果音は Web Audio で合成(音声ファイルなし)。🔊/🔇 は各画面にあり、設定は保存(既定オン)。iOS は最初のタップで有効化。コンボが上がると音が高くなり、5 以上で和音、10 以上で低音ドーン+ファンファーレ、20 以上でビート(フィーバーが終わる・画面を離れる・タブが隠れると止まる)、コンボ切れでガラスの割れる音。
- 正解のあとは約 0.9 秒で自動的に次の問題へ(最後の問題は結果へ)。正解では「つぎへ」ボタンは出さない。不正解だけ、答えを読めるよう「つぎへ / けっかを みる」ボタンで進む。

## クリア条件(えんしゅうりつ マスター)
**全19段(きほん 1〜9 + はってん 12,15,16,18,24,25,36,49,64,81)をマスターし、タイムアタックで 40 秒以内を出す。**
- 段の **マスター** = その段で累計 5 回以上正解 かつ 正答率 80% 以上(4たく・2タップ・ぎゃくびき・タイムアタックの回答が対象。フラッシュカードは対象外)
- タイムアタックは基本 9問・全問正解のときだけベスト記録に入る。

クリアするとエンディング(全画面・プレイ記録のまとめ・クリアバッジ)。ホームにレベル/XP バーとクリアまでの進捗(マスター段 12/19・タイム)を表示。
クリア後もレインボー実績(1000もん・30れんぞく・15びょうぎり・コンプリート)などが残る。

## 起動
```
python3 -m http.server 4199 --bind 127.0.0.1 --directory .
# http://127.0.0.1:4199/ を開く
```
すべて相対パス参照なので `/` 直下でもサブパスでも動く(末尾スラッシュなしで開かれたら `index.html` の inline script が補う)。

## テスト
```
npm test    # node --test(logic.js / progress.js / storage.js)
```

## 構成
- `index.html` / `css/style.css` / `js/app.js`(画面・DOM)
- `js/logic.js`: 純粋関数(整数演算 `314 × n` と受験式整形、4択生成、2タップの整数部/小数部の選択肢と判定、ぎゃくびき、出題キュー、成績集計、ベストタイム)
- `js/progress.js`: 純粋関数(XP・レベル・実績 36 個の判定・連続日数・マスター/クリア判定)。日付・時刻は引数で渡す
- `js/combo.js`: 純粋関数(コンボ段階・キリ番・フィーバー・演出の設計表・ひかえめ変換・コンボ切れ・フラッシュ頻度の制限)
- `js/storage.js`: localStorage ラッパ(キー `pi-kakezan:v2`、`version: 2`。壊れた JSON・使えない環境でも落ちない)
- `js/fx.js`(紙吹雪 canvas・ポップアップ・トースト・全画面オーバーレイ)/ `js/combofx.js`(コンボ演出の実行と掃除)/ `js/sound.js`(Web Audio 合成音・ビート)

## 保存データの移行
v1(キー `pi-kakezan:v1`: 成績・ベストタイム・出題範囲)は初回読み込み時に v2 へ引き継ぐ。過去の正解 1 問につき XP 10 を付与し、累計正解数にも反映。v1 のキーは消さない。
記録リセットは成績・ベストタイム・XP・実績をすべて消す(出題範囲と音の設定は残す)。

## メモ(仕様にない判断)
- クリア用のタイムは 40 秒(基本 9問を 1問あたり約 4.4 秒)。マスターは「5回正解 かつ 正答率 80%」。
- フラッシュカードは自己採点なので成績・マスター・累計正解には入れない(XP +3 とモード実績のみ)。
- 不正解は XP 0(コンボは途切れる)。
- 実績ボーナス XP でレベルが上がった場合も、レベルアップ演出を出す(複数レベル上がっても 1 回)。
- 朝のプレイ = 4:00〜6:59(隠し実績)。
- 正解の自動送りは 0.9 秒。レベルアップ/エンディング表示中はその間待つ。
- 表示の折り返しは空白の位置でだけ(`word-break: keep-all`)。実績トーストは画面下に出し、ボタン操作の邪魔をしない(タップは下のボタンに通る)。
- コンボは「まちがえるまで、クイズをまたいで続く」(同じ起動中のみ。保存しない)。1 回のクイズは 10 問なので、そうしないとフィーバー(20 以上)や実績「20/30れんぞく」に届かないため。
- コンボ切れのガラス演出は 3 コンボ以上から切れたときだけ。それ未満の不正解は軽いシェイクのみ。
- フラッシュは 1 秒に 2 回まで(基準の 3 回より厳しくした)。
