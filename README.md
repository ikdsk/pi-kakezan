# 3.14 の かけざん(円周率の掛け算 暗記アプリ)

中学受験で頻出の「3.14 × n」を、小学生が iPhone / iPad で反復して覚えるための静的 Web アプリ。
ビルド不要のバニラ HTML / CSS / JavaScript(ES modules)、依存パッケージなし、外部通信なし。
仕様は [docs/spec.md](docs/spec.md)。

## モード
| モード | 内容 |
|---|---|
| ひょう | 段ごとの答えの表。答えをタップで隠す/見せる。「ぜんぶ かくす / みせる」 |
| フラッシュカード | 10枚。めくって「おぼえた / まだ」で自己採点 |
| 4たくクイズ | 10問。隣の段の答え・桁ずれ・数字の入れ替わりなど紛らわしい選択肢 |
| にゅうりょくクイズ | 10問。画面内テンキー(OS キーボードは出ない) |
| ぎゃくびき | 「? × 3.14 = 21.98」の ? を4択で答える |
| タイムアタック | 基本 9問をランダム順・入力式。ベストタイム記録 |
| にがて れんしゅう | 正答率が低い段(80%未満)を優先して出題 |
| きろく | 段ごとの正解数/出題数・にがて・直近の間違い・ベストタイム・リセット |

出題範囲はホームで「きほんだけ(1〜9・既定)/ きほん＋はってん / はってんだけ(12,15,16,18,24,25,36,49,64,81)」から選択。

## 起動
```
python3 -m http.server 4199 --bind 127.0.0.1 --directory .
# http://127.0.0.1:4199/ を開く
```
すべて相対パス参照なので `/` 直下でもサブパスでも動く(末尾スラッシュなしで開かれたら `index.html` の inline script が補う)。

## テスト
```
npm test    # node --test(logic.js / storage.js)
```

## 構成
- `index.html` / `css/style.css` / `js/app.js`(画面・DOM)
- `js/logic.js`: 純粋関数(整数演算 `314 × n` と受験式整形、入力の正規化と判定、4択生成、出題キュー、記録集計、にがて抽出)
- `js/storage.js`: localStorage ラッパ(キー `pi-kakezan:v1`、壊れた JSON・使えない環境でも落ちない)

## メモ(仕様にない判断)
- 4択・入力の各クイズは 10問、フラッシュカードも 10枚。全段を一巡してから次の巡に入り、連続して同じ段は出さない。
- 「にがて」= 1問以上解いていて正答率 80% 未満の段。にがてが無いときは「まだ にがては ないよ」と表示。にがて練習は入力式 10問。
- タイムアタックのベスト更新は **9問すべて正解のときのみ**。計時は問題を考えている間だけで、正誤の表示中は止める。
- 「.」だけを押すと「0.」と表示する。空のまま「こたえる」は何もしない(不正解にもならない)。
- 記録リセットは成績とベストタイムを消し、出題範囲の設定は残す。
- フラッシュカードの「おぼえた / まだ」も段ごとの正解/出題数に記録する。
