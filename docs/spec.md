# 円周率の掛け算 暗記アプリ 仕様 (MVP)

中学受験で頻出の「3.14 × n」を、子どもがスマホ / iPad で反復暗記するための Web アプリ。
Tailscale(tailnet 内)で配信する。ログイン・サーバー不要の静的サイト。

## 対象の段
- 基本: 3.14 × 1〜9(必修)
- 発展: 3.14 × 12, 15, 16, 18, 24, 25, 36, 49, 64, 81
  (円の面積・半径の二乗で頻出)
- 設定画面で出題範囲を「基本のみ / 基本+発展 / 発展のみ」から選ぶ(既定: 基本のみ)

## 計算は厳密に
- 浮動小数点で `3.14 * n` を計算しない。整数 `314 * n` を求めて小数点2桁で整形する
  (例: 3.14×7 = 21.98、3.14×10 は 31.4、3.14×25 = 78.5)。
- 末尾の0は省略した受験式表記(31.4, 78.5, 157 など)を正とする。2タップでは整数部 `31`・小数部 `.4` が正解。

## 画面 / モード(すべて日本語、ふりがな不要、小学生が読める言葉)
1. **ひょう(一覧)**: 段ごとの答えを表で表示。各行の答えをタップで隠す/表示(暗記シート方式)。
   「ぜんぶかくす」「ぜんぶみせる」ボタン。
2. **フラッシュカード**: 「3.14 × 7 = ?」→ タップでめくると答え。「おぼえた / まだ」で自己採点。
   自己採点なので段ごとの成績・マスター判定には入れない(おぼえたで XP +3 のみ)。
3. **4たくクイズ**: 10問。選択肢は紛らわしいもの(隣の段の答え、桁ずれ等)を混ぜる。
4. **2タップ チャレンジ**: 10問。1タップ目で整数部(4択)、2タップ目で小数部(4択)を選ぶ。
   2つ選んだ瞬間に判定(確定ボタンなし)。1タップ目は「21.□□」のように表示し、2タップ目の前なら選び直せる。
   整数部は隣の段・±1・±3 など、小数部は他の段の小数部から紛らわしい選択肢を作る。
   小数部が無い答え(例 157)は小数部の選択肢に「なし(.0)」を出す。1文字ずつ入力する方式は使わない。
5. **ぎゃくびき**: 「? × 3.14 = 21.98」→ 7 を答える(4択)。
6. **タイムアタック**: 基本9問をランダム順、2タップ式、経過時間とベスト記録を表示。
   ベスト更新は9問すべて正解のときのみ。計時は考えている間だけ(正誤の表示中は止める)。
7. **じっせき**: 実績の一覧・進捗・未解除の条件ヒント(隠し実績は「???」)。クリア条件と進捗もここ。

## 記録(端末内 localStorage のみ、外部送信なし)
- 段ごとの 正解数 / 出題数、直近の間違い、マスター(★)表示
- タイムアタックのベストタイム
- XP・レベル・解除済み実績・連続プレイ日数・クリア状態
- 記録リセット(確認ダイアログあり。成績・ベスト・レベル・実績を消す。出題範囲と音の設定は残す)
- 保存形式は `version: 2`。v1(成績とベストタイムのみ)は読み込み時に引き継ぐ。

## ゲーム性(派手な演出・XP・実績)
- 正解: 紙吹雪・画面フラッシュ・ボタンの弾み・「+10」ポップアップ。連続正解のコンボは
  3 / 5 / 10 / 20 連続で演出が段階的に派手になる。不正解は軽いシェイクと正しい答えの表示(明るい言い方)。
- XP: 正解 +10、コンボボーナス(最大 +10)、速さボーナス(2秒以内 +5 / 4秒以内 +2)。
  レベルアップは全画面演出(タップでスキップ可)。
- 効果音は Web Audio で合成(音声ファイルなし)。🔊/🔇 は各画面にあり、既定オン。
- `prefers-reduced-motion` のときは動きを弱める(フラッシュ・シェイクなし、紙吹雪は少なめ)。
- 正解後は約 0.9 秒で自動的に次の問題へ(最後の問題は結果へ)。正解では「つぎへ」ボタンを出さない。
  不正解のときだけ「つぎへ / けっかを みる」ボタンを出し、押すまで進まない(正しい答えを読ませるため)。
- 実績 36 個(ブロンズ/シルバー/ゴールド/レインボー)。
- **クリア条件「えんしゅうりつ マスター」**: 全19段(きほん9+はってん10)を各段でマスターし、
  かつタイムアタックで 40 秒以内を出す。マスター = その段で累計 5 回以上正解し、正答率 80% 以上。
  クリアでエンディング演出。クリア後もレインボー実績(コンプリートなど)が残る。

## UX
- スマホ縦向き・iPad 優先。ボタンは大きく(最小 48px)、文字も大きめ。
- 正解/不正解はすぐフィードバック(色+✔/✘+正しい答えを表示)。
- ネットワーク不要で動く(外部 CDN・フォント・解析タグを使わない)。
- 配信パス非依存: すべて相対パスで参照(`/` 直下でもサブパスでも動く)。

## 技術
- ビルド不要のバニラ HTML / CSS / JavaScript(ES modules)。依存パッケージなし。
- 計算・出題・判定・記録集計などのロジックは DOM 非依存の純粋関数モジュールに分け、
  `node --test` でテストする(TDD: RED → GREEN)。
- 配信: `python3 -m http.server <port> --bind 127.0.0.1 --directory <publish dir>` + Tailscale Serve。
